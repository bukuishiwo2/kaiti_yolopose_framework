# 人体三维定位汇报素材（2026-10-19）

## 推荐展示文件

- `human_3d_presentation.mp4`：19 秒，1280×720，5 FPS。小车相机视角、人体骨架、各关节距 base_link 的距离、三维坐标和源年龄。适合汇报播放。
- `rviz_world_and_human.mp4`：15 秒，1400×900，5 FPS。真实 RViz 窗口录制，环境点云、人体骨架和橙色候选目标同时显示。
- `human_3d_keyframe.png`：人体定位视频的关键帧。
- `rviz_world_and_human.png`：实际 RViz 窗口截图；已人工查看，非 Wayland 黑图。

## 原始材料与复现

- `human_3d_localization.mp4`：原 RTSP 直接封装，约 20.067 秒，保留原始捕获文件。开始封装时收到非单调 DTS 警告，不能用它的播放器时间线当作严格延迟指标。推荐展示版去掉首秒、重编码为固定 5 FPS，19 秒，两个展示视频均完整解码检查通过。
- `pose_events_bag/`：约 19.588 秒，247 条消息：二维事件 83 条、三维人体观测 82 条、候选目标状态 82 条。它与视频不是同一时间开始，不能假设逐帧同步。

可在隔离 ROS domain 中回放，勿向原小车域回放：

```bash
source /opt/ros/humble/setup.bash
ROS_DOMAIN_ID=28 ros2 bag play reports/demos/2026-10-19_1701/pose_events_bag
```

## 汇报措辞与限制

建议表述：「已打通人体二维关键点 → 深度反投影 → base/map 三维坐标 → 点云地图可视化，并生成距脚部保留间距的候选目标。」

本素材是实际系统录制，**没有执行自主接近、没有运动轨迹验证、没有摔倒实测**。橙色箭头是候选目标，不表示导航已执行。约 1 秒显示延迟为用户观察反馈；画面中的 age 是发布端源年龄，不是严格玻璃到玻璃测量。坐标精度没有由这些录屏独立证明。

素材包含实验现场和人体画面，仅用于用户要求的汇报；未上传任何外部平台。
