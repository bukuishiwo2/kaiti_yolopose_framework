# 独立小规模修复模型：单体 MILP 与分解的实际对照

日期：2026-11-09。任务目标：独立实现 A0–A5 与算例 B 的验证脚本，核对同范围模型的可行性、最优值、完整剩余排程和约束，记录实际结果。

依据：[统一数学模型与等价性验证设计](../../docs/reviews/repair_unified_model_equivalence_design_2026-11-05.md)。

## 1. 结论与边界

**本轮指定小实例的三路对照全部通过。**三路为：

1. PuLP/CBC 单体 MILP，含对应实例的完整变量/约束。
2. 显式解析投影模型，用作独立数学参照。
3. 主问题 MILP＋外部 LP，逐次生成可行性割和最优性割，不预先填入解析答案。

10 个主算例/变体、21 个固定结构分支共 31 个检查范围、93 路模型结果一致。其中 48 路最优可行、45 路证明不可行。21 个分支包含不同主算例下重复的结构范围，不是 21 类互异的通用规划问题。

对 48 份可行结果独立重建排程、预约、能量和目标，最大约束残差为 **0.0**。11 项负面/证书检查、16 个外部边界探针全部通过。

脚本没有导入或调用现有规划主链、ROS 或机器人服务。运行前后对 76 个现有规划源文件、ROS Python 文件及相关规划配置做 SHA-256 比较，全部保持一致。没有安装依赖、修改旧模型或覆盖已有运行产物。

这证明指定约简实例上的数值一致性与实现基本正确性。**不等于统一通用模型 C1–C8 已全部工程实现，不证明分解性能更优，也不确认学术新颖性。**例如这些实例没有充电或一般多路径选择，不能据此声称相应模块已通过。

## 2. 实际主结果

以下三路状态及目标相同；目标均独立重算通过。

| 实例 | 范围/更新 | 单体 MILP | 解析投影 | 逐次分解 | 共同最优值 |
|---|---|---|---|---|---:|
| A0 | 原资源方向固定 | OPTIMAL | OPTIMAL | OPTIMAL | 29 |
| A1 | 资源方向可选 | OPTIMAL | OPTIMAL | OPTIMAL | 29 |
| A2 | v=95，方向固定 | INFEASIBLE | INFEASIBLE | INFEASIBLE | — |
| A3 | v=95，方向可选 | OPTIMAL | OPTIMAL | OPTIMAL | 49 |
| A4 | A3 再限制 u<=100 | INFEASIBLE | INFEASIBLE | INFEASIBLE | — |
| A5 | 交付最早结束改为94 | INFEASIBLE | INFEASIBLE | INFEASIBLE | — |
| B | C 可分配给 R1/R2、可插入 | OPTIMAL | OPTIMAL | OPTIMAL | 0 |

A0/A1 的最优计划：`d=m=90,u=95,v=96,sigma=0`；A3 为 `d=m=90,u=106,v=95,sigma=1`。

两种可行计划的 R1 电量：`26.5→11.5→10.5→9.5→8.5`；返回最低要求7。R2 电量：`50→49→47→46→45`。A3 的 R2 H 预约 `[95,100]`，R1 H 预约 `[101,106]`，保留1秒安全间隔。B 的最佳 R1 序列为 `A→C→B`，未锁死旧直接后继 `A→B`。

## 3. 确实通过 LP 反馈产生的割

外部 LP 使用 SciPy/HiGHS。不可行时解 phase-I，检查非负乘子、外部变量系数抵消和正违反量；可行时检查原始残差、对偶平稳条件和强对偶 gap。

实际主问题轨迹：

- A0/A1：第一轮外部不可行，产生 `d-u+5<=0`；下一轮产生 `theta>=d-80`；第三轮可行上界与主问题下界相等。
- A3：同样经过上述两条割，第三轮闭合到49。
- A2/A4：时间可行性割后，主问题证明无解。
- A5：除时间割外，进一步产生 `0.5*d-46.5<=0`，随后主问题证明无解。

这些割来自 LP 的实际对偶/phase-I 解，不是直接写入分解求解器的三个解析约束。解析投影仅在第二路独立使用。实际记录的分解证书最大平稳残差为0；完整乘子、矩阵、每轮候选、割及范围hash保存在原始 JSON。

## 4. 完整重建与反例检查

验证器独立于建模行实现：

- A：检查整数方向和范围锁定、所有变量界、交付可用时刻、监护覆盖、两机行驶和非重叠、真实预约与1秒间隔、任务期限、返回时刻、剩余能量、epigraph 和全成本。
- B：检查分配唯一性、能力、固定 owner、所有 arc/分配整数性、起终点和任务流平衡、连通/无循环、任务时窗/时长、同机非重叠、A/B外部相对顺序、固定分支和完整目标。
- A 的路线/owner本来已固定；B 无充电、共享资源或携物约束。验证范围与实例实际变量一致，不声称覆盖没有出现的功能。

11 项负面/证书检查：

| 检查 | 实测结果 |
|---|---|
| 独立时间窗组合 u=104,v=96 | 真实 H 顺序检查拒绝 |
| 把外部 monitor 成本漏掉，声称19 | 独立成本核算拒绝；正确29 |
| 分数资源方向，声称28.05 | 整数性/安全间隔检查拒绝；正确MILP为49 |
| 再扣历史监护耗电 | 能量重建拒绝 |
| 硬固定旧 monitor end=80 | 监护覆盖检查拒绝 |
| A4 忽略硬期限 | 期限/范围检查拒绝 |
| A5 忽略能量边界 | 返回电量检查拒绝 |
| 时间失败候选 | 得到并核查有效 phase-I 证书 |
| 电量失败候选 | 得到并核查有效 phase-I 证书 |
| B 错误固定旧直接后继 | 实际解得1，区别于正确0 |
| B仅R1有能力且错误固定旧后继 | 实际证明不可行，区别于正确0 |

另对16个外部 `(d,u)` 边界点求LP，与解析条件 `d<=93,u>=d+5` 及外部最优成本 `d-80` 比较，全部一致。有限探针是补充检查，不能代替连续可行域的解析证明。
