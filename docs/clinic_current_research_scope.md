# 当前论文研究范围与Clinic证据边界

更新日期：2026-11-26。本页是当前研究方向和阶段状态的入口；较早的家居场景方案、公共空间 V3 计划、旧 benchmark 和 Clinic 早期设计继续保留为历史来源，不再覆盖本页的研究范围。

论文题目保持为《动态环境下融合语义感知的多智能体协同规划研究》。三项研究内容固定如下，不因阶段性工程实现改变主线：

1. **动态环境下的语义事件感知**：人体关键点、LSTM时序行为识别、跌倒事件稳定化和观测质量。
2. **面向动态事件的机器人任务生成**：将带来源与时间有效性的感知事实转成事件生命周期、空间语义、核验结论、任务依赖和执行前提。
3. **面向动态语义事件的多机器人协同分配与反馈重规划**：确认事件后保护已执行事实与已派发承诺，使用当前角色、路线和资源条件安排应急及常态任务。执行反馈触发约束更新，重新安排受影响的后续任务。

## 研究内容三的核心问题

多智能体协同规划是论文核心。内容一输出事件证据，内容二输出带空间目标和依赖的任务，内容三决定多机器人分工、排程和在线调整。

- **事件到达后的动态协同分配**：事件任务束如何与常态任务和多个机器人状态共同协调？原MILP仍作为模型基础；当前优先以同快照强基线判断联合分配的必要条件，不预设联合方法更优。
- **反馈改变下一轮分工与排程**：两次路径查询拒绝已通过同快照回放写回约束，更新后的计划可通过模型验证并保留已派发任务与预约。在线入口接入一次有条件的重算，替代路径、共同并发衔接和实际提交仍待验证。[反馈重规划回放](../reports/benchmarks/clinic_feedback_repair_2026-11-26.md)

## 当前证据状态

| 研究部分 | 已有功能证据 | 仍缺的研究证据 |
|---|---|---|
| 内容一 | Clinic使用真实UR Fall视频回放，真实YOLO Pose和32帧LSTM产生模型输出；A区正例和误报样本均进入系统链路 | 输入视频属于历史训练/开发域，不能作为独立泛化集；质量门控、遮挡和重新观测需求尚需配对验证 |
| 内容二 | event-task/v1可对候选去重、显式核验、任务生成/关闭进行有限场景接入；空间来源可标为`video_source_registered` | RGB-D代表位置、候选目标与可达性及任务依赖仍缺独立配对实验；视频源注册不是传感器定位 |
| 内容三 | 原MILP、Nav2和服务ACK已在A区真实视频正例三机功能闭环中衔接；存在动态承诺保护/修复样本；另有离线分配强基线与多事件能力验证 | 联合分配并未显示普遍优势；局部修复是条件性结果；A区实体策略配对、B区完整服务资格和多事件实体执行尚未齐备 |

**有限打通判断：**在`verification/visual_positive_2026-11-18_c1/positive_02`这一受控样本中，内容一→二→三已经形成真实视频模型输出、事件/任务生成、原MILP、Nav2与服务ACK的功能闭环。这不表示三项研究全部完成、独立性能收益成立或学术创新已获支持。

**空间目标判断：**当前已验证的真实正例位置来源是`video_source_registered`。Clinic把区域登记位置映射到核验、监护、取货和交付服务节点；事件位置可选择不同预登记服务区域，但不会从任意人体像素在线生成精确三维导航目标。A区正例有完整执行资格；B区完整取货路径资格未通过。`sensor_estimated` RGB-D位置分支仍待独立验证。

A 区的人工备选站位试验独立报告路径筛选与执行验收。四个路径查询中三项通过。南侧代表点由 R1 实测跟踪、停稳并完成空间服务，东侧代表点仍只有查询证据。该结果对应单机受控占位条件。[A 区空间站位验收](../reports/benchmarks/clinic_spatial_stand_2026-11-26.md)

在固定跌倒候选和机器人起点的占区对照中，Clinic 在 V1 存在占用时把既有 `E1:verify` 更新为南侧点。正式任务、MILP 输入及实际 Nav2 请求目标一致，原 worker 完成核验回执。两点均不可用时保留待核验任务。该对照使用受控地图占区及已限定的 R1 资格。[正式核验站位对照](../reports/benchmarks/clinic_verify_stand_switch_2026-11-26.md)

同一南侧点已在 A 区三机短队列完成后续应急响应。MILP 提交时保留 R3 的 TL 巡检，R1 在收到该巡检的清空回执后出发监护，R2 在监护开始后取货并完成实际交付。直接前往 M1 和经 V3 的并发接近均有失败记录。[三机响应实测](../reports/benchmarks/clinic_stand_switch_response_2026-11-26.md)

**仿真与性能判断：**实际 Clinic 工作区为`/home/yhc/clinic_planning_ws`；仓库`experiments/clinic`是上传用源码快照。Fast/Standard功能验收通过但时间目标未达。不得把一次功能闭环、离线模型可行、仿真路线实测、性能收益和学术创新当成同一种结论。

## 不再扩展的方向

RTAB-Map/SLAM、机器人自身定位、完整人体三维骨架重建、独立底层路径规划、新的 LTL/PlanSys2 规划器、强化学习调度和新的复杂识别网络不再作为当前论文新增内容。已有实现和历史实验保留作回归、复现和边界说明。
