# 研究范围收口与完成计划

更新日期：2026-11-26

论文《动态环境下融合语义感知的多智能体协同规划研究》研究动态任务到达和执行状态变化时，多机器人如何在能力、跨机器人依赖和共享资源约束下协同分工、排程和执行。Clinic 是典型动态环境的验证场景。实验采用先验地图、现有定位或仿真真值、Nav2 和已接入的预约、FIFO、keepout 等执行机制。

**动态事件感知 → 语义事件向可执行任务转换 → 多智能体协同规划 → 执行反馈与动态协调**

| 研究内容 | 输入 | 输出 |
|---|---|---|
| 1. 动态环境下的语义事件感知 | 视频、YOLO Pose 关键点及置信度、LSTM 时序窗口 | 行为候选、置信度、观测时间和质量、失效或重新观测需求 |
| 2. 面向动态事件的机器人任务生成 | 感知证据、核验反馈、代表位置、已知地图及服务规则 | 事件身份与版本、带空间目标的任务、激活/释放条件、依赖图、可达性和安全资格 |
| 3. 面向动态语义事件的多机器人协同分配与反馈重规划（核心） | 任务图、当前角色资格、路线与资源条件、机器人可用时刻与位置、已执行事实与已派发承诺 | 归属、顺序、时刻、预约和派发；执行反馈更新约束后，重新生成受影响的任务后缀 |

> 语义事件确认后，在保留已执行事实和已派发任务承诺的条件下，联合安排应急任务与剩余常态任务。规划器使用当前有效的机器人角色、路线和资源条件生成计划。当执行反馈表明候选方案不可用时，更新对应约束，重新规划受影响的后续任务。

研究重点是事件如何改变任务与协同约束，以及执行反馈如何改变下一次分工和排程。

## 后续开发与验收

1. **事件入链。** 用真实视频正例、无跌倒、漏关键点和不同长度遮挡配对。记录源时间到候选及核验任务的延迟、误触发、重复任务与恢复。不可观测窗口保持未知并保留尚有效的历史证据。过期后请求重新观测或核验，避免由缺帧推出正常或跌倒。
2. **生成可执行任务。** 在固定事件类型下替换有效位置、过期位置和不可达位置，再固定位置改变事件状态和需求。比较任务图、目标版本、替代目标与拒绝原因。空间目标先验收 Nav2 查询，再对代表点独立核验跟踪、稳定到达、服务回执和适用的租约。A 区受控占区已验证核验站位切换、双目标拒绝和备选点正式执行。最小 RGB-D 链以同步深度、原图时间 TF 和稳定关键点估计地图代表位置，按有效率、位置误差和任务目标合格率验收。[分阶段实测](../reports/benchmarks/clinic_spatial_stand_2026-11-26.md) · [正式任务目标切换](../reports/benchmarks/clinic_verify_stand_switch_2026-11-26.md)
3. **协同分工与异步执行。** 选择已具有执行资格的 A 区短队列作为后续同条件配对候选。两组共用资格域、目标、预算及承诺约束，比较固定常态归属与合法后缀开放归属。记录实际交付、常态完成和资源释放。长队列在 R3 进站资格通过前保留为离线证据。
4. **反馈重规划。** 区分候选路径拒绝、活动导航失效及资源可用时间变化。记录失败涉及的机器人、路径阶段、占用和时刻，明确约束是否为暂时不可用。对活动任务保留原承诺与资源状态，依据真实完成、取消或清空回执更新。对未派发的受影响后缀重新求解，保留失败前后两版约束、归属、顺序和时刻，验证更新后的实际执行。
