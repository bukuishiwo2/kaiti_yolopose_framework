# 研究范围收口与完成计划

更新日期：2026-11-25

论文《动态环境下融合语义感知的多智能体协同规划研究》研究动态任务到达和执行状态变化时，多机器人如何在能力、跨机器人依赖和共享资源约束下协同分工、排程和执行。Clinic 是典型动态环境的验证场景。实验采用先验地图、现有定位或仿真真值、Nav2 和已接入的预约、FIFO、keepout 等执行机制。

**动态事件感知 → 语义事件向可执行任务转换 → 多智能体协同规划 → 执行反馈与动态协调**

| 研究内容 | 输入 | 输出 |
|---|---|---|
| 1. 动态环境下的语义事件感知 | 视频、YOLO Pose 关键点及置信度、LSTM 时序窗口 | 行为候选、置信度、观测时间和质量、失效或重新观测需求 |
| 2. 面向动态事件的机器人任务生成 | 感知证据、核验反馈、代表位置、已知地图及服务规则 | 事件身份与版本、带空间目标的任务、激活/释放条件、依赖图、可达性和安全资格 |
| 3. 动态任务环境下的多智能体协同规划（核心） | 任务图、能力、可用时刻与位置、旅行代价、资源、已承诺执行状态 | 归属、顺序、时刻、预约及派发；异步反馈更新状态并触发在线协调 |

## 后续开发与验收

1. **事件入链。** 用真实视频正例、无跌倒、漏关键点和不同长度遮挡配对。记录源时间到候选及核验任务的延迟、误触发、重复任务与恢复。不可观测窗口保持未知并保留尚有效的历史证据。过期后请求重新观测或核验，避免由缺帧推出正常或跌倒。
2. **生成可执行任务。** 在固定事件类型下替换有效位置、过期位置和不可达位置，再固定位置改变事件状态和需求。比较任务图、目标版本、替代目标与拒绝原因。最小 RGB-D 链以同步深度、原图时间 TF 和稳定关键点估计地图代表位置，按有效率、位置误差和任务目标合格率验收。候选服务目标检查站位清空、安全距离、路径可达、资源资格和新鲜度。
3. **协同分工与异步执行。** 首先在 A 区对候选角色及实际并发补齐路径、姿态、到达、租约和服务 ACK 资格。选择 E1 在执行、E2 到达时存在任务竞争的固定快照，加入常态任务和共享 G1，复用 B0 固定归属重排、B1 最早可服务插入、B2 受限 MILP、B3 合法后缀联合分配。比较同输入、同预算、同验证器下的任务完成率、响应/交付、正常任务等待、资源冲突、首次可验证解及承诺变化。记录实际而非预测的服务开始/结束。先验证常态与首个动态任务配对，再由独立多事件模型过渡至实时 E2。
4. **在线协调与修复。** 用异步开始/完成、占用变化和新任务到达触发更新；按相同的已完成事实、活动前缀、货物归属和资源约束比较局部修复与热启动全后缀。度量合法恢复、改派、时移和求解延迟；报告失败、预算超时与回退。禁止为了展示收益人为收紧阈值或缩小基线能力。
