# 局部结构—全局时序修复：统一数学模型与小规模等价性验证设计

日期：2026-11-05。

任务目标：将[上一轮修复方案](calvo_tapf_pc_repair_proposal_2026-11-05.md)收敛为共同数学模型，明确同范围单体 MILP 与分解模型的逐项对应，用解析实例给出应验证的可行域、最优值与反例。

本文是待实现的研究规范，不覆盖[现有序列 MILP 说明](../milp_model_spec.md)或[V3 冻结配置](../../configs/public_space_v3.yaml)。本轮只写文档，未修改代码、配置或运行求解器。文中的算例结果为解析推导，不是软件实验成绩。

## 1. 统一的研究对象与语义

### 1.1 单轮确定性剩余计划

在固定 `world_revision` 和当前绝对时刻 `t0` 下，输入实际执行状态、旧计划、当前有效任务、服务位置、路径代价和资源状态。求所有当前必须执行任务的剩余计划。输入不包含未来真值；新的观测由下一轮更新处理。

第一版限定：有限任务、连续时间、容量为 1 的共享资源；每个机器人及节点对最多一条事先给定的可用路径；任务和资源状态在一轮内确定。没有可用路径就删除相应 arc，不允许算法自行假设替代路径。

这里建立的是任务/路径预约级模型，不是完整连续运动规划。地图、路径和可停等位置的几何正确性是输入前提。

所有纳入的任务必须执行；算法不能通过丢掉任务获得可行性。取消由上游明确给定，已取消任务不进入剩余任务集。可选任务选择、跨机物资交接、监护接力与随机持续时间不进入第一版。

### 1.2 当前状态规范化，防止重复计费

每台机器人有独立的虚拟起点状态 `(位置, r_i, E_i^0)`，其中 `r_i>=t0` 为可开始模型内动作的时刻，`E_i^0` 是该时刻可用电量。

- 空闲机器人：起点为实际位置，`r_i=t0`，电量为实际快照。
- 已锁定且可准确预测的短前缀：可推进到该前缀结束；前缀的剩余资源预约以固定区间保留，不能因推进状态而消失。前缀耗电只扣一次。
- 正在执行的监护：不推进到旧预测结束。将其作为强制首任务的“监护延续”，`s_m=t0`，初始电量取 t0 实测；结束 `f_m` 是变量。实际开始时刻作为历史事实单独保存。
- 其他不可中断服务可作为剩余时长已知的强制首任务。行进中的机器人必须给定可信剩余前缀与预约；不能把它直接瞬移到目的地。本模型不研究该前缀的几何求解。

监护若有总最小时长，剩余最小时长为 `max(0, actual_start+d_min_total-t0)`。历史耗电、历史响应时间和已完成任务不再重复计入可优化的未来成本。

已开始任务的开始期限按实际开始时刻在历史中核验，不能再对其延续 start=t0 施加旧开始期限。已完成 pickup 与 monitor 的历史覆盖同样按实际开始/结束记录核验；残余任务只约束未来尚未完成部分。

全队不得统一等待到最晚 active finish；每台机器人使用自己的起点状态。

## 2. 集合、参数与变量

### 2.1 集合及主要参数

| 符号 | 定义 |
|---|---|
| `I` | 机器人集合 |
| `J=J_s ∪ J_m ∪ J_c` | 普通服务、监护、充电任务；集合不重叠 |
| `E` | 有效事件，每个事件含所需 monitor、pickup、deliver 的任务索引 |
| `R` | 容量 1 的资源集合 |
| `P ⊆ J×J` | 跨任务前驱关系 |
| `0_i, ω_i` | 机器人 i 的起点、固定安全终点，均不是普通任务 |
| `A_i` | 可用有向 arc，含起点、任务和终点连接，排除自环及不可达连接 |
| `C_j ⊆ I` | 任务 j 的能力/权限允许机器人 |
| `r_j,d_j,D_j` | 任务释放时刻、普通/充电任务固定时长、期限 |
| `J_H,J_S` | 硬完成期限与软完成期限的任务集 |
| `J_H^start` | 另有硬开始期限的任务集，例如核验/监护响应 |
| `τ_iuv` | arc 的固定无等待行驶时长 |
| `(α_l,β_l,r_l)` | 路径第 l 次资源使用的进入/离开比例与资源标识；按路径顺序排列 |
| `δ_pq` | 两次同资源预约之间要求的安全间隔 |
| `κ_i^move,κ_i^idle` | 移动、非服务等待的耗电率 |
| `ε_ij,ρ_ij` | 执行 j 的固定耗电及按持续时间耗电率 |
| `E_i^max,E_i^min` | 电量上限与安全下限 |
| `T` | 本轮有限规划终点，任务及安全返回均需在 T 内完成 |

安全终点位置预先指定，不在这一版中优化“返回哪个充电点”。普通服务的 `ρ_ij` 可为 0；监护延续只按剩余时间耗电，通常令其再次启动的固定耗电为 0。

期限含义必须由任务类型明确：开始期限约束 s，完成期限约束 f；硬期限进约束，软期限才用延误变量。monitor 的响应期限约束开始，不把它误写成监护必须在响应期限前结束。

### 2.2 离散变量

| 符号 | 类型及含义 |
|---|---|
| `x_ij` | 二元，i 是否执行 j |
| `a_iuv` | 二元，i 是否直接从 u 到 v |
| `k_pq` | 二元，两次候选资源预约 p、q 是否同时选中 |
| `z_pq` | 二元，同时选中时 1 表示 p 在 q 前，0 表示 q 在 p 前 |

**所有尚未固定的离散选择都属于主问题。**不能让外部 LP 暗中选择资源顺序、分配、路径或充电站。`k` 可由其他二元变量确定，但为清晰仍显式列出。

### 2.3 连续变量

`s_j,f_j` 为服务开始/结束；`q_ij` 为顺序秩，可连续；`dep_j` 为实际离开服务节点的时刻。

每条候选 arc 有出发 `D_iuv`、途中的允许停等 `w_iuv,l>=0` 和总非行驶间隙 `h_iuv>=0`。每次候选预约 p 有进入/离开 `η_p,ξ_p`，选中指示 `b_p` 取 a、1 或固定值。

`B^-_ij,B^+_ij` 为任务前后电量；`g_iuv` 为 arc 上移动及等待耗电；`ℓ_ij` 为服务耗电；`Q_ij` 为充电增益；`B_i^end` 为终点电量。

延误 `L_j`、开始/结束绝对偏移 `Δs_j,Δf_j` 及其他成本辅助变量均连续。所有时间、能量和辅助变量给出有限合法界；时间变量的模型上界不是每轮求解的 wall-clock 预算。

## 3. 共同约束：单体与分解必须逐项相同

以下用 `b=1 ⇒ constraint` 简写指示约束。实际 MILP 可用合法 big-M 线性化；本文不假定当前代码已经实现。每行 M 必须由该行的变量界计算，时间与电量不能无条件复用同一个 M。

### C1：唯一分配与能力

```text
sum_i x_ij = 1                         for j in J
x_ij = 0                              if i not in C_j
```

执行中的 monitor、已携物资者及不可撤销动作进一步固定其 owner。不是固定角色的离线场景才允许相应重分配。

### C2：机器人路径流与无子回路

```text
sum_v a_i,0_i,v = 1
sum_u a_i,u,ω_i = 1
sum_u a_i,u,j = x_ij = sum_v a_i,j,v
x_ij <= q_ij <= |J|*x_ij
a_iuv=1 => q_iv >= q_iu + 1            for u,v in J
```

没有任务的机器人也有起点到安全终点的 arc，代价、耗时与预约按真实给定路径处理。起点无入边、终点无出边；不同机器人不能连接彼此虚拟节点。正时长之外仍保留秩约束，避免零行驶边形成子回路。

强制首任务 g：固定 `x_ig=1,a_i,0_i,g=1`，并设置正确的零距离/剩余前缀连接。

### C3：服务时间与期限

```text
t0 <= s_j <= f_j <= T
s_j >= r_j
f_j = s_j + d_j                       for j in J_s ∪ J_c
f_m >= s_m + d_m^min                   for j=m in J_m
f_j <= D_j                            for j in J_H
s_j <= D_j^start                      for j in J_H^start
L_j >= f_j-D_j, L_j>=0                for j in J_S
```

monitor 可变时长不使用普通任务固定 duration 等式。软期限标记不意味着允许违反监护/资源等硬约束。

### C4：前驱、取送同机与监护覆盖

```text
s_v >= f_u                            for (u,v) in P
x_i,pickup(e) = x_i,deliver(e)         for every i
s_monitor(e) <= s_pickup(e)
f_monitor(e) >= f_deliver(e)
```

监护占据机器人整个 `[s_m,f_m]`，通过 C2/C5 阻止其同时离场执行其他任务。已经完成 pickup 时，不重建其任务和耗电，改为固定 deliver 的物资持有者。

已完成前驱的实际结束时刻变为后继释放下界。事件关闭仅由上游确定，剩余 monitor 的合法终点/待取消任务在快照规范化时固定，优化器不能自行关闭事件。

### C5：行驶、等待和新的连接

对每条选中 `a_iuv=1`，令起点 `f_0_i=r_i`，终点 `s_ω_i` 为到达安全终点时刻：

```text
D_iuv >= f_u
s_v = D_iuv + τ_iuv + sum_l w_iuv,l
h_iuv = s_v - f_u - τ_iuv >= 0
u in J => dep_u = D_iuv
```

起点等待 `D-f_u` 和途中等待均计入 h。服务资源在离场前仍被占据时，使用 C6 的延长预约。等式禁止在目的地出现未建模的任意等待；所需等待应放在已验证的安全停等位置。

只允许在路径给定的安全驻留点等待；某一资源之前没有安全停等点则该 `w_l=0`。若驻留本身占用其他资源，必须增加对应预约。这里的“可等待”是共同输入前提，不是碰撞安全证明。

不选中 arc 的 D、w、h、g 置 0，选中时的等式用指示约束激活。局部任务插入后，新连接 arc 的 travel、能量和资源使用全部来自更新后的共同路径目录。

终点显式满足 `t0<=s_ω_i<=T`，`E_i^min<=B_i^end<=E_i^max`；候选预约、出发和驻留变量也具有与其选中状态一致的有限界。

### C6：路径和服务资源预约

路径第 l 次资源使用：

```text
b_p = a_iuv
a_iuv=1 => η_p = D_iuv + α_l*τ_iuv + sum_{h<=l} w_iuv,h
a_iuv=1 => ξ_p = η_p + (β_l-α_l)*τ_iuv
0 <= η_p <= ξ_p <= T*b_p
```

服务资源 j,r 的预约指示为 1，进入 `η=s_j`。若机器人停留就继续占据该资源，离开 `ξ=dep_j`；若只是服务时使用的工具，离开 `ξ=f_j`。这种语义由资源类型预先确定，不能给不同算法采用不同定义。

固定前缀/外部承诺的预约也加入同一目录，进入、离开为常量。

每对同资源候选 p,q：

```text
k_pq <= b_p, k_pq <= b_q
k_pq >= b_p+b_q-1
z_pq <= k_pq
k_pq=1,z_pq=1 => η_q >= ξ_p + δ_pq
k_pq=1,z_pq=0 => η_p >= ξ_q + δ_pq
```

不同时选中时将 z 规范为 0，避免无效二元选择影响比较。预约可互相串联；每一对约束均与分配和 arc 选择一致。

临时占用释放时刻 `A_r`：`b_p=1 ⇒ η_p>=A_r`。永久 blocked 资源禁止未来预约 `b_p=0`。若已执行/不可撤销预约与新安全状态冲突，输入先进入共同安全处理，不通过放松硬约束伪造可行计划。

### C7：电量递推与充电

```text
E_i^min*x_ij <= B^-_ij,B^+_ij <= E_i^max*x_ij
0 <= ℓ_ij <= M_E*x_ij
x_ij=1 => ℓ_ij = ε_ij + ρ_ij*(f_j-s_j)
0 <= Q_ij <= Qmax_ij*x_ij
Q_ij = 0                              if j not in J_c
Q_ij <= charging_rate_ij*d_j           if j in J_c
B^+_ij = B^-_ij - ℓ_ij + Q_ij
```

任务外不选中的前后电量、耗电和充电均为 0。对选中 arc：

```text
g_iuv = κ_i^move*τ_iuv + κ_i^idle*h_iuv
B^-_iv = B^+_iu - g_iuv               if v in J
B_i^end = B^+_iu - g_iuv              if v=ω_i
B_i^end >= E_i^min
```

其中 `B^+_i,0_i=E_i^0`。返回路径已经包含在终点 arc 中，不再重复扣“返回余量”。充电增益既受持续时间限制，也受电量上限限制。

监护耗电按延续 `f_m-t0` 计算，已发生部分不能再次扣除。若未来采用非线性能耗，当前 LP 分解等价性不自动适用，需共同线性化或重新建模。

### C8：不可撤销属性与执行事实

实际开始的服务延续固定 start、owner 和强制首连接；旧预测 end 不自动固定。确实不可变的近期预约、已执行资源顺序和授权约束均硬固定。合法可撤销安排由下一节范围 F 控制。

强制中断、人员位置失效等场景的安全模式由共同上游决定；本模型不将“维持旧计划”置于安全约束之上。

## 4. 修复范围 F：固定哪些属性，释放哪些属性

`F` 至少包含：可改变 owner 的任务集 `S_x`、可重新插入/排序的任务集 `S_o`、允许改变的旧资源先后对 `S_z`；输入候选 arc 和硬承诺在所有方法中相同。

1. `j not in S_x`：固定 `x_ij=bar_x_ij`。新任务需明确列入允许分配集，不能引用不存在的旧 owner。
2. 对每台机器人，把未释放排序的外部任务按旧次序形成子序列。固定其 owner，并保留相对次序，例如连续两个外部任务 u,v 满足 `q_iv>=q_iu+1`。为避免含糊，所有可换 owner 的任务都列入 `S_o`；即 `S_x ⊆ S_o`。
3. **不固定这些外部任务之间的旧直接后继 arc。**核心任务可以插入中间；外部子序列顺序仍保持。
4. 不在 `S_z` 中、且两次旧预约仍被选中的资源对保留旧方向：旧 p 在前则 `z_pq=k_pq`，旧 q 在前则 `z_pq=0`。不选中的旧预约不强迫其继续存在。
5. 新连接产生的新资源对没有旧方向，必须作为主问题离散变量选择，或由共同协议明确固定，不能交给 LP 临时决定。
6. 未来时刻、等待和电量只要不属于 C8 硬事实，就保持可调。范围 F 不以“时间受影响的全部后继”定义。

F 扩大只放松上述可撤销结构约束，不能改变路径、deadline、安全间隔、任务集合或目标权重。在同一快照下，`F⊆F' ⇒ feasible(M_F)⊆feasible(M_F')`。这个包含关系不意味着更大的范围在有限预算下一定更快。

## 5. 共同目标：所有成本逐项计一次

参考计划先移除已完成/明确取消任务，校正延续任务的历史 start；保留仍有意义的旧时刻、owner 和次序。新任务没有旧安排，不人为计重分配或时移；必要取消造成的常数成本单列。

定义非负权重、统一单位/归一化后：

```text
J = α*C_travel + β*C_response + γ*C_soft_deadline
    + δ*C_wait + η*C_energy + sum_ij c^assign_ij*x_ij
    + μ_x*D_owner + μ_a*D_adjacency + μ_z*D_resource
    + μ_s*D_start + μ_f*D_finish
```

- `C_travel=sum τ_iuv*a_iuv`，包含终点返回；已锁定前缀成本为共同常数。
- `C_response` 是事件相应任务的开始减释放时刻；已开始事件使用实际开始作为常数，不以延续 start=t0 伪造新响应。
- `C_soft_deadline=sum priority_j*L_j`，仅 soft 任务。
- `C_wait=sum h_iuv`，服务/监护持续时间不再重复当等待。
- `C_energy=sum g_iuv+sum ℓ_ij`，是未来消耗，充电不作为负消耗奖励；充电成本如需计入另设共同非负项。
- `D_owner=sum_{old j}(1-x_bar_owner(j),j)`。
- `D_adjacency=sum_{old valid (i,u,v)}(1-a_iuv)`，计算旧相邻连接破坏；插入也可能产生该成本，不将它错误称作“外部相对顺序反转数”。
- `D_resource` 只统计仍同时使用的匹配旧预约对反向：旧 z=1 时取 `k-z`，旧 z=0 时取 z。
- `D_start=sum Δs_j,D_finish=sum Δf_j`，分别满足 `Δs>=±(s-bar_s)`、`Δf>=±(f-bar_f)`。

比较时须分别输出 owner、旧连接、资源方向和时间偏移，不能只报一项“修改任务数”。已硬固定且不可改变的历史属性不参与可避免变化代价。

绝对值/正部用 epigraph 辅助变量线性化；非负目标权重保证最优值等价。权重为 0 时辅助变量可能有松弛，日志中的实际变化仍由最终计划重算，不要求无权重辅助变量本身恰好取最小。

这是统一研究目标的定义，不是宣称当前代码的权重和耗电已按此实现。小算例可将部分权重置 0 来隔离某一约束；正式方法评价必须统一、预先冻结同一权重。

## 6. 同范围单体 MILP 与分解的严格对应

### 6.1 单体模型 M_F

单体 `M_F` 同时保留全部任务的变量和 C1–C8，施加第 4 节完全相同的范围 F，最小化第 5 节目标。它不是更小任务集，也不是固定外部时间的原 LocalRepair。

用 w 表示全部离散变量，包括资源顺序和新连接选择；v 表示放在主问题的连续变量；z 表示其余连续变量（与带下标的二元资源变量 z_pq 不同）。顺序秩等连续辅助变量可放在任一侧，只要映射明确且不重复。任务越过接口时的 s/f、电量、dep 和所有候选跨边界预约都须保留。

线性化后将模型逐行分为：

```text
M_F: min c_w^T w + c_v^T v + c_z^T z + c0
     H_F*w + K*v >= h_F
     A*z >= b - B*w - D*v
     w binary, v,z have their stated domains
```

只含 w/v 的行进入第一块；任何含 z 的行进入第二块，包括变量界。z 视作自由实变量，其原上下界已变成第二块约束行。静态候选目录使 A 对当前范围/快照固定；指示选择进入右端，不能根据当前提案遗漏“看起来未选中”的行。

### 6.2 联合可行域与价值函数

```text
P_F = {(w,v): exists z, A*z >= b-B*w-D*v}
phi_F(w,v) = min_z {c_z^T z: A*z >= b-B*w-D*v}
```

若无延拓，`phi=+infinity`。有限域及合法成本界排除有限可行情况下的负无穷。

精确分解主问题：

```text
min c_w^T w + c_v^T v + theta + c0
subject to H_F*w+K*v>=h_F
           (w,v) in P_F
           theta >= phi_F(w,v)
```

实现时不必显式枚举整个投影，但联合关系和成本下界不能丢失。时间窗只能代替其中的部分约束，不能无条件代替 P_F。

### 6.3 约束及目标对照表

| 单体 M_F 中的对象 | 分解中的对应 | 必须核对 |
|---|---|---|
| x、arc、资源选中和顺序 | 同一个 w 和同一范围约束 | 外部 LP 无剩余整数选择 |
| 核心 s/f、跨边界接口 | v | 单位、上下界和索引相同 |
| 外部 s/f、等待、能量及成本 epigraph | z | 仍可联动，不替换成旧数值 |
| 前驱、监护结束、路径资源和能量跨界行 | A/B/D 的对应行 | 不能只迁移前驱而漏资源/电量 |
| 外部相对顺序 | H/K 或外部行 | 保序不等于固定旧直接后继 |
| 所有业务与变化代价 | c_w、c_v、c_z、c0 的不重叠分拆 | 每项只算一次；监护端点时移不能遗漏 |
| 不可撤销事实和 prefix 预约 | 同一硬行/常量 | 两模型采用同一实际状态 |

### 6.4 等价性命题与证明

**命题。**在同一快照、同一 F、完整静态线性编码和上述精确价值函数下，分解模型与 M_F 对每个 `(w,v)` 的延拓可行性一致；其最优值相同，包括二者同时不可行情形。一个投影点可以有多个外部延拓，辅助变量/非唯一最优计划不要求数值逐项相同。

证明分两方向：

1. 对任意单体可行 `(w,v,z)`，同一个 `(w,v)` 满足主问题和 P_F；其外部最小成本 `phi<=c_z^T z`，所以分解最优值不大于单体最优值。
2. 对任意分解可行 `(w,v,theta)`，P_F 给出外部延拓；选达到 phi 的有界 LP 最优解 z，得到单体可行计划，且 `c_z^T z=phi<=theta`，所以单体最优值不大于分解最优值。

两不等式给出相等。若只有可行域投影而没有 theta/phi 的正确计费，只能证明可行性等价，不能证明目标等价。

该结论是模型变换的正确性，不是新算法相对研究现状的新颖性，也不保证有限求解时间。

### 6.5 可行性割与最优性割的可检查条件

令 `r=b-Bw-Dv`。对于外部 LP `min c_z^T z, Az>=r`：

- 可行性证据：`lambda>=0,A^T lambda=0,lambda^T r>0`，意味着该候选无延拓；加入 `lambda^T(b-Bw-Dv)<=0`。
- 成本下界：`pi>=0,A^T pi=c_z`，给出 `theta>=pi^T(b-Bw-Dv)`。

每条割记录矩阵/快照/范围 hash 和证书，不以 solver 返回“失败”代替证书。换范围、换快照或改变 A 后不得自动复用。

迭代主问题的 theta 初始下界由外部成本和变量界给出；不得在尚无成本割时让 theta 无界。本例外部目标为非负 h_m，可以使用 theta>=0。

有限割近似通常是 P_F/phi 的放松，主问题给下界 LB；只有外部 LP 已给出完整延拓并核算全成本时才得到可行上界 UB。首个可行解不等于已证明最优；使用 `UB-LB` 检查 gap。超时记 UNKNOWN，不输出不可行结论。

## 7. 算例 A：监护、交付、共享通道和剩余电量

### 7.1 全部参数与任务映射

绝对时间单位为秒；当前 `t0=60`，规划结束 `T=150`。此例 owner/机器人任务次序均固定，仅研究时间与一个资源先后选择。所有未给权重的成本均为 0；路径/固定服务成本是对所有分支相同的常数，从本例 J 中省略。

| 对象 | 参数与语义 |
|---|---|
| R1 | 正在监护，实际开始 20；t0 剩余电量 26.5，电量上限 60 |
| monitor 延续 M | `s_M=60,f_M=m`，强制 R1 首任务；剩余耗电率 0.5/秒、无再次启动耗电；`m>=d` |
| R1 后续 U | 开始 u，服务 10 秒；M→U 行驶 5 秒，全部经过 H，预约 `[u-5,u]` |
| R1 电量 | M→U 耗电 1，U 耗电 1，U→安全点耗电 1；终点最低 7；非服务等待耗电率为 0 |
| R2 | 已持有所需物资；可信锁定前缀结束后在交付点可用，更新后 ready=80，电量 50；固定前缀不占本例 H |
| delivery D | 开始 `d-10`，固定服务 10 秒；`90<=d<=100`，此下界来自更新后的 ready |
| R2 后续 V | 交付后到 H 入口至少 5 秒；H 进入 v，占 `[v,v+5]`，随后服务 10 秒；V 完成 deadline=120，故 `v<=105` |
| R2 返回 | V 后返回安全点需 5 秒；电量充足；可取 D/V 各耗电 1、移动耗电率 0.2、终点最低 7 |
| H | 容量 1，预约间安全间隔 1 秒 |
| U 完成 deadline | 默认 120，即 `u<=110` |
| 旧计划参考 | `bar_d=80,bar_m=80,bar_u=90,bar_v=92`，旧 H 次序为 R1 在前；更新前 R2 ready=70 |

R2 的 ready=80、电量=50 是前缀结束状态，不能再额外扣同一前缀。旧计划参考在新 ready 下失效是本例触发，不要求参考计划仍对更新后输入可行。

原 pickup 已完成，以物资持有事实固定 deliver owner，不重复创建 pickup。两台机器人的服务点不同且不共享其他服务资源。本例无额外未知障碍或未列出的资源。

### 7.2 显式同范围单体模型

定义 `sigma=0` 为保留 R1 在前，`sigma=1` 为改成 R2 在前。与一般模型映射为 `b_p=b_q=k_pq=1,z_pq=1-sigma`。

全部有效变量和约束可约简为：

```text
90 <= d <= 100
60 <= m <= 150
60 <= u <= 110
60 <= v <= 105
m >= d
u >= m + 5
v >= d + 5

v-u >= 1  - 200*sigma
u-v >= 11 - 200*(1-sigma)
sigma in {0,1}

E = 26.5 - 0.5*(m-60)
E-3 >= 7
0 <= E <= 60

h_m >= m-80
h_m >= 80-m
0 <= h_m <= 70
```

`u-v>=11` 来自 R2 先过：R1 入 H 为 u-5，R2 出 H 为 v+5，加 1 秒间隔得 `u-5>=v+6`。不能误写成 u>=v+1。

200 是本例的安全 M，不是建议的通用参数：在给定 u/v 域上足以完全关闭另一分支。正式模型逐行推导 M。所有分支实际时间均需经下面的预约还原核查。

共同目标为：

```text
J = (d-80) + h_m + (u-90) + (v-92) + 10*sigma
```

更新后 d/m/u/v 的下界保证这些线性时移项均为非负方向，等于对应绝对偏移；`h_m` 计 monitor 结束偏移。`10*sigma` 是本算例的资源顺序变化代价。这个测试权重用于核查算术，不是 V3 新默认权重。

R1 从 t0 的电量继续递推，合并得到：

`E=56.5-0.5m>=10 ⇔ m<=93`。

因此未来 monitor 即使在时间上可以延长，电量也限制它至多到 93 秒。若错误按 `m-20` 再扣一次历史耗电，会制造假不可行。

### 7.3 完全对应的分解

主问题变量为 `(sigma,d,u,v,theta)`，保留上面的时间界、R2 可用性、两条资源方向约束、sigma 域及范围固定条件。

外部 LP 变量 `(m,E,h_m)`：

```text
phi(d,u) = min h_m
subject to m>=d
           m<=u-5
           E=56.5-0.5m
           E>=10, 0<=E<=60
           h_m>=m-80, h_m>=80-m
           60<=m<=150, 0<=h_m<=70
```

主问题目标为：

`(d-80)+(u-90)+(v-92)+10*sigma+theta`。

在主问题已有的 `d>=90,u<=110` 下，精确消元得到：

```text
外部可延拓 iff d<=93 and u>=d+5
可延拓时 phi(d,u)=d-80
```

因此加入两条可行性割与一条成本割即精确表示本例外部：

```text
u >= d+5
d <= 93
theta >= d-80
```

逆向构造为 `m=d,E=56.5-0.5d,h_m=d-80`。对任何满足上述投影且满足主问题其余约束的候选，这组值都构成合法延拓；这不是只检查了一个最优点。

### 7.4 逐条可检查的割证书

**时间可行性割：**将 `m>=d` 与 `-m>=5-u` 相加，得到 `0>=d+5-u`。乘子均为 1，外部 m 系数抵消。候选 `(d,u)=(90,94)` 违反该割 1 秒。

**电量可行性割：**将以下三行分别乘 `0.5,1,1` 后相加：

```text
m >= d
-E-0.5m >= -56.5
E >= 10
```

得到 `0>=0.5d-46.5`，即 d<=93。候选 d=94 违反原缩放割 0.5，能量失配无法靠增加时间修复。

**成本割：**`h_m>=m-80` 与 `m>=d` 相加得 `h_m>=d-80`。它是合法外部成本下界。不能只移交 m 的约束却忘记 monitor 结束偏移。

这里只用代数即可检查乘子非负、变量抵消和候选被排除的原因；未来 LP 实现须能导出同等有效证据，但不要求返回完全同一组乘子。

### 7.5 基础情况 A0：只需时间调整

范围固定 `sigma=0`。资源约束为 `v>=u+1`。

各项成本对变量递增，故最优为：

```text
d=90, m=90, u=95, v=96, sigma=0
h_m=10
J*=10+10+5+4=29
```

下界证据：d>=90、h_m>=10、u>=95、v>=96，给出 J>=29；该点达到下界，故是解析最优值，不依赖 solver。

还原完整排程和能量：

| 动作 | 时间/电量 |
|---|---|
| R1 monitor 延续 | `[60,90]`，电量 26.5→11.5 |
| R1 H | `[90,95]`，耗电 1，U 前电量 10.5 |
| R1 U | `[95,105]`，耗电 1，余 9.5 |
| R1 返回安全点 | `[105,110]`，耗电 1，终点 8.5>=7 |
| R2 D | `[80,90]` |
| R2 到 H 及停等 | 最早到 H 入口 95，等待至 96 |
| R2 H | `[96,101]`，与 R1 间隔 1 |
| R2 V 与返回 | `[101,111]` 服务，`[111,116]` 返回 |

按给定 R2 耗电，其安全终点电量为 `50-1-2-1-1=45>=7`。R1 等待率为 0 是此解析实例的显式参数，不推广为实车结论。

若 sigma 也自由，另一分支最小 `v=95,u=106,d=m=90`，成本 49，故全范围本例仍选 29。

### 7.6 变体矩阵与解析期望

| 编号 | 相对 A0 的输入/范围变化 | 解析期望 | 要检查的模型性质 |
|---|---|---|---|
| A0 | sigma 固定 0 | J*=29 | 同结构重定时与完整成本 |
| A1 | sigma 可选 | J*=29，选择 sigma=0 | 无需变化时不额外改资源方向 |
| A2 | v 固定 95，sigma 固定 0 | INFEASIBLE | u>=95 且 u<=94 冲突 |
| A3 | v 固定 95，sigma 可选 | J*=49，sigma=1 | 释放一项结构后恢复 |
| A4 | A3 再将 u 上限设为 100 | INFEASIBLE | 两方向均不可行；不能放松间隔获胜 |
| A5 | d 下限改 94，sigma 可选 | INFEASIBLE | monitor 结束与剩余能量联合限制 |

A3 的可行点为 `d=m=90,v=95,u=106`，J=`10+10+16+3+10=49`。sigma=0 分支已由 A2 证伪；sigma=1 时 v=95 推出 u>=106，其余正成本下界给出49，故最优值确切。

A3 还原：R2 H 为 `[95,100]`，R1 H 为 `[101,106]`；R1 在服务点停等至101再离开，U为 `[106,116]`，返回至121，均在T内。停等若在其他场景消耗电量或占资源，必须按 C6/C7 计入；本例已明确 idle rate=0、无该附加资源。

这些变体是预先给定的验证输入，不是在看完方法结果后修改期限。A4 是完整输入的另一测试，不能与 A3 混成同场景方法对照。

### 7.7 联合可行域为何不能换成独立窗口

固定 d=90、sigma=0，消去外部后有：

```text
95<=u<=110, 95<=v<=105, v>=u+1
```

精确边际范围是 `u∈[95,104],v∈[96,105]`。各自合法的组合 `(u,v)=(104,96)` 却违反共同资源顺序；(104,105) 与 (95,96) 分别可行。

这验证的是候选可行域，不是声称 A0 的正权重目标一定会选到错误组合。独立窗口模型应在固定候选探针上暴露错误，而不能凭一次最优值碰巧相同就判为等价。

## 8. 算例 B：局部新任务插入与外部保序

此例另有 `t0=0,T=10`、两台机器人，同一安全位置、全部行驶时间为 0、无共享资源、能量充足且本例耗电为 0。任务参数：

| 任务 | owner/允许 owner | release | duration | hard finish deadline |
|---|---|---:|---:|---:|
| A | 固定 R1 | 0 | 2 | 2 |
| B | 固定 R1 | 4 | 2 | 6 |
| C，新任务 | R1 或 R2 | 2 | 2 | 4 |

时窗强制 `A=[0,2],C=[2,4],B=[4,6]`。外部子序列为 R1 的 A≺B。范围只开放 C 的 owner 与插入，保留外部 A/B owner 及相对次序。

本例目标特意仅取：

`J_B=(s_C-2)+x_R2,C`。

新任务没有旧 owner，不计重分配；`x_R2,C` 是预设能力/分配偏好代价，其他统一目标分量权重为0。它只是等价性测试目标。

穷举两个 owner 即得：

| C owner | R1 序列 | R2 序列 | 最优值 |
|---|---|---|---:|
| R1 | A→C→B | 空 | 0 |
| R2 | A→B | C | 1 |

正确的 M_F 与分解都应返回最优值0，并可还原 C 插入 A/B 之间的计划。A≺B仍然满足。

若错误固定旧直接后继 `a_R1,A,B=1`，则错误排除了第一行，得到1；再将 C 能力限制为仅 R1，会错误判不可行。第二个变体同时检查无效能力分配能否被拒绝。

本例的零 travel 仍须有 C2 秩约束。验证目标包含完整可行分支和最佳分支，不要求存在唯一的无关辅助变量取值。

## 9. 有意错误的模型，用于证明检查能抓到问题

这些是负面验证，不是正式竞争基线，不得把非法模型的低成本当方法提升。

| 错误 | 具体探针 | 应观察到的错误与正确答案 |
|---|---|---|
| 只保留独立时间窗 | A0 固定 d=90，探针 u=104,v=96 | 错误接受；正确联合模型拒绝 |
| 漏计外部 monitor 时移 | A0 将 theta 直接置0并当成完整成本 | 会把候选成本写成19；正确全成本为29；仅作为 LB 则合法但尚未闭合gap |
| 外部 LP 擅自放松资源整数方向 | A3 将 sigma 放松到[0,1] | u=95,v=95,sigma=1/200 可得28.05，但H的1秒间隔不满足；正确 MILP 为49 |
| 重复扣历史监护能耗 | A0 将 m-60 改成 m-20 | 制造假不可行；正确值29 |
| 把旧 monitor end=80 硬冻结 | A0 | 与 m>=90冲突；正确模型只固定历史start/owner |
| 固定外部旧直接后继 | 算例 B | 错误最优值1；正确值0 |
| 松弛硬期限以换可行性 | A4 | 非法“恢复”；正确为INFEASIBLE |
| 忽略电量边界 | A5 | 错误接受m>=94；正确为INFEASIBLE |

A3 的分数方向反例以本例 M=200 为基础：sigma=1/200 使 `v-u>=1-200sigma` 在 u=v=95 时成立，另一条也松弛；但真实预约 `[90,95]` 和 `[95,100]` 缺少1秒间隔。它说明“外部 LP”成立的前提是先固定全部结构选择，而不是把未确定整数全部连续松弛。

## 10. 未来小规模数值验证的执行设计

### 10.1 第一层：解析答案作为独立 oracle

先实现以上 A0–A5、算例 B 两个允许 owner 分支及 B 的单能力变体。三种求解方式必须使用相同输入：

1. 同范围单体 M_F。
2. 精确解析投影/价值函数主问题。
3. 逐次 LP 可行性割＋最优性割的分解实现。

对照 J*=29/49/0/1 与不可行状态；输出每项成本、预约和能量轨迹。解析答案不能从新实现自己的输出自动生成。

本轮已给出解析推导，三种数值实现均为 **NOT_RUN**。

### 10.2 第二层：逐结构穷举，检查整个可行分支

在2–3机器人、3–6任务、很少共享资源的构造实例上，对所有实际允许的 owner、机器人排列、资源方向结构 w 穷举。先用能力、前驱和范围 F 筛除显然非法的结构，不使用测试真值跳过困难结构。

固定每个 w 后，M_F 本身也是 LP。比较其可行状态、最优值与分解延拓 LP：任一分支状态不同即FAIL，不因全局最优值相同而忽略。

穷举实例须控制可接受结构数量并记录枚举总数/跳过原因，不能把只采样几个 w 称为穷举。对比较大的小实例，先选受控任务关系保证可完整枚举，不承诺任意6任务结构都廉价。

### 10.3 第三层：可行域双向包含

对 A 这种已有显式投影的实例：

- 用代数消元得到边界行，再逆向构造外部变量，已在 §7.3 完成。
- 对每条投影不等式，在单体固定结构 LP 上最大化其违反量，应不大于0。
- 对投影多面体的顶点和代表边界点构造延拓；结合显式线性描述检查逆向包含。

有限网格采样不能证明连续可行域等价。普通随机实例若只做状态/目标比较，结论必须写“数值一致性检查”，不替代一般命题的证明。

### 10.4 第四层：证书、目标和重建

每个失败候选保存 `lambda`，核查非负性、`A^Tlambda=0`、正违反量与割的适用hash；每个成本割保存 pi，核查 `A^Tpi=c_z`。证书可有不同缩放，不比较字符串或固定乘子数组。

每个可行解还原所有任务和路径预约，独立重算：唯一分配、前驱、执行事实、跨机监护覆盖、资源间隔、期限、全部电量与充电、同机取送、外部子序列、全成本。

允许最优计划不唯一；比较最优值、可延拓性和实际约束，不要求两算法输出完全相同时间向量。辅助绝对值有零权重时以计划重算值为准。

### 10.5 容差与状态判据

解析实例以分数/精确小数为理论答案。数值检查建议在归一化后固定：时间/能量可行性容差 `1e-7`，目标差容差 `1e-6*(1+abs(J_ref))`，并保存原始最大残差；正式实现需结合所用LP/MILP求解器容差统一设置。

结果标签：

| 标签 | 条件 |
|---|---|
| PASS_EQUIVALENT | 两模型已证明最优/不可行，约束与目标在容差内一致 |
| FAIL_MODEL | 某分支状态、投影、目标或重建不一致 |
| UNKNOWN_BUDGET | 任一方超时且缺少完成证明；不能算通过或不可行 |
| CERTIFICATE_UNAVAILABLE | 缺有效对偶/不可行性证据；可以保留候选日志但不能冒称已验割 |

仅有相同 feasible incumbent 不足以打 `PASS_EQUIVALENT`。未运行一律 `NOT_RUN`，不填预计提升百分比。
