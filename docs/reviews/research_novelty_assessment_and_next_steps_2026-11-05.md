# 三项研究内容的学术性、新颖性证据与下一步研究决策

日期：2026-11-05。固定题目：《动态环境下融合语义感知的多智能体协同规划研究》。

任务目标：保持“环境认知与人体行为感知—语义事件构建与任务生成—多智能体协同任务规划”三项边界，从已有研究、项目实现和可证伪实验判断创新是否成立。

本文是研究评审，不修改 V3 冻结方案，不授权或执行机器人实验；所有方法建议均为待验证候选。没有新增训练、外部方法复现或性能结果。

## 1. 直接结论

**研究主线成立；现有材料不足以认定三个独立学术创新已经成立。**

| 研究内容 | 现阶段可支持的结论 | 创新判断 | 建议投入 |
|---|---|---|---|
| 一：环境认知与人体行为感知 | 有现成 SLAM 基础、姿态/时序识别原型、开发口径结果 | 目前主要是成熟方法应用与训练策略验证，独立方法创新证据最弱 | 先做移动观测条件下的强基线失效诊断；不预定新网络 |
| 二：语义事件构建与任务生成 | 有四态、Episode、任务工厂；实车三维融合和候选接近基础 | 有研究潜力，但“保持事件＋空间落点＋模板”尚不能排除标准事件推断与规则组合的解释 | 保留完整事件—空间—任务链，检验抽象机制是否有不可替代差异 |
| 三：多智能体协同任务规划 | 有离线分配排程、局部修复和验证器 | 最接近可形成核心算法贡献的位置，但现有局部修复未超过相关研究 | 优先做同目标全量基线、成熟修复与大邻域搜索对照 |

这里的“证据弱”不等于已经证明没有创新。相反，“值得研究”也不等于已有新颖性。需要区分研究问题有价值、方法与已有工作有差异、差异产生可复核收益三个层次。

不建议为了凑三个创新增加通行预测、主动感知、LLM、强化学习等独立方向。三个研究内容可以组织完整论文；若确实要求每项均为独立方法创新，则必须逐项形成证据，现有工程成果不能自动填补。

## 3. 已有成果究竟证明了什么

### 3.1 感知：有可工作基线，尚无机器人视角泛化结论

历史 hard-negative 实验中 LSTM 稳定逐帧 F1 从 0.7800 到 0.7979，Precision 从 0.8059 到 0.8657，Recall 从 0.7557 到 0.7401。ADL 误报帧从 273 到 162，约下降 40.7%。这是同一报告内的对照，不能与其他版本的 LSTM 数字拼成新的对比表。

这些结果支持辅助负样本在该开发评估口径下有作用，尚不支持新时序算法、独立医院 test 的泛化、移动相机鲁棒性或与先进骨架方法的优越性。反复用于阈值和抽样比例选择的数据不能再无条件称作独立 test。

实现细节也限制了候选主张：当前 54 维特征已经含每个关节置信度，并按框中心/尺度归一化。因此“首次加入置信度”或“首次尺度归一化”连对项目自身都不是有效差异。当前时序检测主要按帧索引入队；源时间戳贯通不等于模型已经对不规则时间间隔建模。输出名 `seq_probability_calibrated` 在所查推理路径中直接取模型 score，字段名称不能证明完成校准。

32 帧在 4–5 FPS 下大约覆盖 6.4–8 秒，只能作为时间尺度诊断线索，不能据此认定论文新问题，更不能认定整段时间都是不可避免的检测延迟。

### 3.2 事件与空间：连通与精度、语义正确性需要分开

四态、Episode 与任务工厂已有原型。真实 RGB-D 深度采样、反投影、TF、地图骨架与候选接近点已有十月实测基础。但短测 `map_valid` 或三维点有效率不是定位真值误差；标准差生成对角 covariance 也不是经过覆盖率验证的概率置信域。

`WorldState` 已有按 track、外部 event ID、符号位置关联活动 Episode 的规则，以及按任务 ID 幂等注册。它们说明生命周期原型存在，不等于已经完成带位置不确定性的事件关联或新事件推断算法。

10-19 后续实际进行了受控点动，点动里程计约 0.02624 m；左脚方向接近记录约 1.96496 m。后者被回退计时提前结束，未正常触发到达阈值。应写“受控接近原型与恢复记录”，不能写“未做任何运动”，也不能写“已完成 Nav2 自主到达和双机器人服务”。

### 3.3 规划：判别样例不是方法先进性

六月 Full-Replan 改 2 项、LocalRepair 改 0 项，是刻意加入未来对称任务的机制判别样例。它可以展示冻结的效果，不能排除：全量求解器只是选了另一个等价最优解，或全量分支没有同样的变化惩罚。

[正式 MILP 说明](../milp_model_spec.md)还明确六月历史配置走 legacy solver；不能用历史样例代替正式 `sequence_arc_v2` 的学术验证。

所查 `dynamic_repair.py` 中，影响传播显式包含任务前驱与 incumbent 机器人后继链，未在该图中显式建立共享资源未来链；与方法说明声称的传播范围需要区分。该函数还先算 full 再算 local，因此当前函数总调用时间不能用单个 local solver 时间替代。未来若改成 local 优先再回退，应按新部署路径重新测量。

LTLf 当前是有限轨迹规格与验收；任务由规则/任务工厂生成，排程由 MILP 求解。没有自动机驱动任务合成证据，不能写成已经实现 LTL 自动规划。

## 5. 第一项：把研究问题落在观测机制与识别可靠性的关系

### 5.1 可成立的问题表述

**在移动机器人导致的视角变化、部分可见与不规则采样共同出现时，如何区分人体自身动作变化与观测变化，得到可迁移的在线行为证据？**

其学术性来自可研究的观测模型与泛化条件。它适用于机器人巡检、辅助生活与人机交互；4 FPS、某次掉帧或某个阈值只是检验实例。

但不能预先断言视角适应模型都不支持动态视角，也不能断言标准缺测模型必然失效。需要明确比较：现成视角处理、重采样、缺测模型分别或组合后，是否已经足够。

### 5.2 先诊断，再选方法

输入可写为 `O_t=(关键点, confidence, visibility mask, source time, 可用机器人位姿及其误差)`，输出为因果行为证据。第一版不要求同时发明新 SLAM 和新识别骨干。

先比较：当前 LSTM/TCN；统一物理时间窗重采样＋LSTM；mask/时间间隔感知的成熟时序模型；一种适配骨架模型；必要时加入视角归一化。只有这些强基线仍有系统性缺陷，才考虑观测运动与人体动力学分离的表示或训练机制。坐标变换本身是基础工具，不能命名后当创新。

若新方法使用 RGB-D、里程计或额外训练数据，必须让对应强基线得到相同信息，并另报相对原 RGB 基线的系统增益，否则无法归因于算法。

验证应跨人员、视频、场景，分别覆盖机器人静止/移动、持续遮挡、距离与采样抖动；真实变化与人工退化分别报告。随机丢点和图像旋转不能完整替代真实自运动与遮挡。主要比较事件召回、误报/小时、响应延迟及计算开销，报告正常观测下是否退化。

**否定条件：**重采样或成熟缺测/视角模型已达到相同效果；改进仅来自更多输入、数据或更长观察时间。届时将第一项定位为可靠感知基础或评测贡献，不包装为新识别算法。

## 6. 第二项：研究“何时有依据生成何种任务”的抽象机制

### 6.1 研究对象不能缩成平滑分数

本层保留完整链条：证据 → 事件实例 → 位置/区域与有效性 → 安全边界/服务点 → 任务及依赖。

**候选学术问题：不确定且间断的时空观测，如何形成具有持续身份与有效执行前提的事件—任务抽象，使错误释放、漏释放和任务反复修订在响应约束下可控？**

这里要辨析三种不同事实：事件是否仍存在、位置是否仍可信、某角色任务的空间前提是否成立。例如事件持续但交付点过期，应维护事件、暂停或更新交付任务；不能把位置失效等同事件关闭。事件已确认但没有可靠位置，也不能据此生成有确定导航目标的交付任务。

### 6.2 与现有方法真正需要比较的东西

pEC 已有事件持续与概率推理，语义规划已有概率谓词，HMM/HSMM 也能处理隐藏状态。因此贡献不能停在“把真实事件和观测可见性分开”，更不能止于增加未知状态和几个字段。

需要先实现一个很强的组合参照：**成熟事件推断＋空间有效性检查＋同一任务模板与生命周期规则**。它应获得相同的历史、质量、位置误差和计算预算。若它能解释全部收益，新方法就没有独立优势。

待查新的具体落点是：在证据相关、空间前提失效与恢复的条件下，推断和任务抽象如何共同更新，而不只在分类结果后独立加门控。必须给出事件状态、空间有效性和角色前提的联合建模或明确抽象规则，说明相对标准组合多解决了哪类问题；不以“统一框架”代替机制差异。

形式化时可令 `B_t` 表示事件状态与位置的信念，`Pre_k` 表示任务角色 k 的释放前提。考察 `P(事件有效 ∧ Pre_k | 历史证据)`，而非随意把分类分数与位置置信度相乘。**这只是定义问题，不是新算法**；联合概率需要有估计依据，未校准时不能赋予其风险保证。

本层保证的是任务描述具有有效依据与局部执行前提；多任务在机器人、期限和资源约束下能否同时完成仍由第三项判断，不提前承诺全局可执行。

### 6.3 可检验性质与实验

可以研究：有条件的任务释放正确性、事件身份连续性、观测退化时的保持/恢复、空间证据更新到任务前提更新的一致性。性质必须注明关联、误差界、传感器失效等假设；任务 ID 去重属于正确性基础，不能单独算学术贡献。

主比较采用同一感知日志：直接触发；调优迟滞＋模板；HSMM＋模板；pEC/RTEC 类方法＋相同空间规则；当前四态＋Episode；候选方法。原版与适配/重实现分开，未复现的标 NOT_RUN。

标注既要有事件实例真值，也要有独立定义的角色任务及有效目标真值，不能用自己的模板输出验证自己。比较任务生成 precision/recall、漏生成、重复、错误取消、目标有效率和释放延迟。在同事件召回与响应预算下比较误任务；随后固定第三层检验无效导航与计划修订。

**否定条件：**成熟推断加相同空间规则已达到同样表现；优势来自延迟更长、召回更低或独占额外信息。若仅新增语义字段与状态表，则保留为系统设计贡献，不能称新时空推断方法。

## 7. 第三项：把新颖性集中在耦合变化下的修复决策，而非工具组合

### 7.1 已经有竞争力的研究问题，但通用机制不再新

**候选学术问题：当事件任务、服务位置或共享通道发生变化时，如何在跨机器人时序/占位耦合及执行承诺下，选择足够而不过度的修复子问题，兼顾可行恢复、业务代价和在线计算预算？**

它保留原有分配—排程—动态修复主线。研究对象可以推广到巡检响应、取送与持续值守，不依赖某个 corridor 名称。

Calvo 的修复已传播跨机延迟。TAPF-PC LNS 已有前驱闭包、边界处理及冲突/松弛量邻域。因此“建立依赖图、冻结无关任务、不可行时扩张”只能作为算法起点，尚不能声称新颖。

### 7.2 下一步应该查清的精确差异

需要逐条核对已有模型能否自然表达：持续监护的结束由另一机器人的交付决定；取送绑定且不得隐式交接；服务位置或事件存在变化导致任务/资源约束更新；旧通道预约与活动承诺的可撤销范围。

这些未必都是新约束。持续监护可用跨任务区间约束表达，取送同机、电量、资源互斥也有成熟形式。真正有机会的贡献是：这些耦合变化使某类既有修复假设不再充分时，提出有明确适用条件的边界判据或更有效的求解策略。必须展示标准建模与标准 LNS 不能等价完成的差异，否则只是新应用实例。

一个可探索但未确认原创的方案是：保留不可撤销执行承诺，将可重协商承诺作为带代价的边界变量；仅释放受到具体约束冲突影响的任务，允许重分配/重排，并检查局部结果与外部预约、电量和监护区间的一致性。冲突诊断、假设文字和邻域扩张本身都是已知思想，需继续查新；CBC 也不能假定会直接提供最小 IIS。

性质分析可先限定在有限任务/固定候选路线下：若外部冻结部分有效，所有跨边界约束被保留且局部解满足这些约束，则拼接结果满足同一离散模型。还可分析单调扩张终止。它们是需要证明的条件性质，不是已经获得的定理；不意味着连续执行无碰撞，也不自动保证最小修复集合。

### 7.3 全量强基线必须同目标、同信息

统一目标可写成业务成本加计划变化代价；若用词典序或非劣约束，所有方法都使用相同定义。变化应区分重分配、顺序、时间偏移和外部预约撤销，不以总项数掩盖差异。

在相同硬约束、前缀和目标下，局部冻结限制了可行域。因此全量问题的最优代价不大于局部问题最优代价。新算法可以争取预算内更快获得合格计划、较好质量—时间关系；不能宣称同一目标下严格优于已求得的全量全局最优值。若确有这种结果，应先检查约束、时间限制和目标口径。

最低对照组：

1. Full-Replan。
2. Full-Replan＋相同变化惩罚、相同 incumbent/warm start 条件。
3. 简单时间顺延；以及适配的 Calvo 原版修复，在共同能力子问题上比较。
4. 当前固定依赖闭包 LocalRepair。
5. 通用 LNS/ALNS，加入前驱/冲突/低松弛量邻域；预算与新法一致。
6. 候选改进法。

要同时包含局部可解、需要扩大边界、必须全量、全局不可行及无扰动情况。输入相同任务和世界快照，先隔离感知差异。小规模用精确解核查可行性和 gap；扩大任务/机器人/约束密度与扰动频率，报告任务完成、响应、违约、冲突、变化量、回退和全过程 p95。规模与种子数量由先导后冻结，不把一张七任务甘特图当规模证据。

**否定条件：**全量同惩罚或通用 LNS 已有同样质量—时间表现；改进仅来自去掉约束、缩短未来时域、给新法更多预算或漏计回退时间。若仅节省求解时间，贡献就按在线求解效率表述，不扩大为更优任务模型。

## 8. 学术性不是“问题听起来大”，也不要求三章各发明一个大模型

来自实车的故障可以成为研究线索，关键在于能否抽象到一类方法的适用条件、提出可迁移机制并用外部研究检验。

| 项目观察 | 原样修复的性质 | 可能上升的研究问题 | 仍需跨越的证据门槛 |
|---|---|---|---|
| 显示排队、网络配置、某次服务失效 | 部署维护 | 通常无需单列论文创新 | 恢复正确运行即可，不用扩大为算法 |
| 32 帧跨越的物理时间变长 | 时间尺度适配 | 观测采样机制变化下的在线行为识别 | 超过重采样/成熟缺测模型，且跨真实观测条件成立 |
| 同一事件重复创建任务 | 生命周期工程 | 不确定时空事件的持续身份与任务抽象 | 超过 pEC/HSMM＋同规则，而非只增加去重字段 |
| 某走廊阻塞后全队计划变化 | 运行实例 | 耦合约束变化下的最小干预修复与预算分配 | 超过同惩罚全量、成熟修复与 LNS，而非只对比无惩罚全量 |

工程组合也可以形成系统研究贡献，但需证明有明确的一般化设计原则、可复现评价和跨实例收益。若学院要求算法创新，系统接通不能替代该要求；是否满足学位标准由实际培养要求和导师评审确定。

## 9. 建议按四个研究交付包推进

### A：先固定问题与最接近工作，不改研究内容

产出三张方法差异卡，每张写清：同类最接近论文、其明确假设/机制、目标条件、待验证不足、新方法差异、主指标、否定条件。每项选 2–3 篇直接竞争工作深读，追踪引用与后续工作；上面的表只是筛查起点。

优先深读第三项的 Calvo VI-A 和 TAPF-PC 4.2–4.3，再读第二项的 pEC/tensor-pEC 与语义规划，最后为第一项选择机器人视角、缺测和跨视角基线。论文全文、作者代码 commit、是否原版/适配和复现状态都登记。只有摘要时不要填写“原方法不支持”。

### B：先做能否决现有候选的小型离线先导

| 先导 | 立即要回答的问题 | 本批交付 | 决策 |
|---|---|---|---|
| P3，最高优先 | 现有 LocalRepair 的收益是否在同惩罚 Full-Replan 和通用邻域方法下仍存在？ | 正式 sequence 模型的配对输入、强基线结果、总时间与目标分解 | 收益消失则改算法或降低主张，不扩系统掩盖 |
| P2 | 四态/Episode 的任务收益，是否能被成熟推断＋相同空间/任务规则复现？ | 同感知回放、独立事件/任务标注、错误任务—延迟曲线及空间失效案例 | 不能超过则先定位为系统支撑 |
| P1 | 时间对齐/成熟缺测模型是否已解决主要机器人观测退化？ | 隔离 split、物理时间窗口核查、静止/移动观测分层表 | 无剩余机制缺口就不额外造网络 |

先导只用于方法选择，不能再当最终 test。出现有利案例还需要负对照和不利案例，不把人为构造的“新法赢”直接当真实分布。

### C：只实现先导支持的机制，同时保留三项边界

优先在第三项形成一个可明确解释的算法差异；第二项若有独立时空抽象差异，再形成第二个方法贡献。第一项在证据不足时保留为可靠感知基础，不强行补一个“注意力＋LSTM”创新。

若明确要求三个独立创新，则第一项也必须通过 A/B 的查新和先导；不能在无额外数据/时间的情况下承诺三个都成立。研究执行次序不等于论文叙述次序，论文仍按一、二、三展开。

### D：正式独立评价后接完整系统

第一项固定下游；第二项使用相同感知回放并固定规划器；第三项使用相同任务输入。端到端实验另做逐层消融，不能把上游改善全部计入规划创新。

以独立视频、事件或 run 为统计单位；报告配对差与 95% CI、失败/超时分母、调参预算、硬件与总在线时间。正常条件、跨场景/拓扑条件和模型失配都要保留。两机器人固定角色成功只证明合作可行；算法评价需有可选择的任务分配或排序空间，另与同等双机器人基线比较。

真实单车证据与多机器人仿真分开报告。保留 V3 工程门禁，DUCT 接近实验不替代医院双机闭环。当前研究查新和离线先导无需先解决所有实车显示/导航问题，但也不能因此提前声称在线闭环完成。
